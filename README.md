# Gusto POS - Restaurant & Table Management System

A modern Point-of-Sale (POS) and operations management platform designed to handle daily workflows, table orders, and billing for hospitality businesses.

## Key Features
- **Interactive Floor Plan:** Visual table layout with real-time occupancy and status updates.
- **Order & Bill Management:** Table-based product additions, dynamic pricing, and split-payment billing logic.
- **Reporting & Analytics:** Administrative dashboard displaying daily sales summaries, expense tracking, and order history.
- **Receipt Generation:** Print-ready formatting for orders and invoices.

## Tech Stack
- **Frontend:** Next.js, React, TypeScript, Tailwind CSS
- **Backend & Data:** Node.js, Express.js, MongoDB
